# Sonic Memory — Visual Language

Sonic Memory should be recognizable before anyone reads a label.

## The visual promise

- **The center is now.** It should feel energetic, immediate, and causally connected to the audio.
- **Distance is memory.** Older sound should occupy larger radii as coherent shells, petals, ribbons, and filaments—not disappear into random dust.
- **A beat travels.** Transients should create legible outward-moving wavefronts.
- **Harmony leaves architecture.** Sustained tones should create persistent, layered structures that remain visible long enough to inspect.
- **Silence clears honestly.** Empty history should not fabricate structure.

## Rendering priorities

1. Readable temporal depth at a glance.
2. Coherent neighboring points rather than randomized spectral noise.
3. Enough luminance to survive alongside the fluid droplet and particle layers.
4. Graceful behavior across quiet and loud recordings through frame-relative spectral normalization.
5. Deterministic forms: the same passage and settings should produce the same sculpture.

## QA target

The isolated automated hero frame must show a volumetric structure extending well beyond the central emitter. A passing state check is not sufficient; image analysis must confirm that luminous structure occupies a substantial radial area outside the droplet-sized core.
